## Why this row matters more than its size

Shell-tier fixtures contend for host-global names, so at the fleet floor the same commit
is green or red depending on what else is running. The cost is not flakiness but **loss
of evidential value**: a lane cannot trust its own green, `gate/land.sh` inherits the
contention at landing, and an unreproduced report is ambiguous between a real defect and
a collision.

That ambiguity was live and expensive on 2026-08-03: the orchestrator twice doubted a
lane's honest `clean`. (Those particular doubts turned out to have a different cause —
see V3-0.24, a stale runner — but the ambiguity is what made them plausible.)

**Parking this row means suite results remain conditionally trustworthy.** Treat a
single unreproduced shell-tier failure as inconclusive until it is re-run in isolation.

## What is genuinely closed — verified by execution

- **Runtime allocation works.** Each launch fixture uses a private cloned repository and
  a per-run ref prefix; three-way concurrent contention passes with
  `ag-fleet-launch-proof` seeded and a foreign singleton lock held.
- **The token check fires on the direct paths.** Replacing the `REF_PREFIX` assignment
  with `REF_PREFIX="ag-fleet-launch"` exits 1 before any ref is created:
  `fixture ref prefix is not unique to this run`. Assembling the same fixed value from
  two variables also exits 1.
- **The static lock catches direct literals**: `--branch ag-fleet-launch-proof` exits 1
  with `contains a fixed fixture ref`.

## The open blocker — a lock that checks a proxy, not the property

`tools/shell-test-tier.test.ts:52-55`, `orchestrator/fleet/launch-lane.test.sh:9-17,80,87`.

**The value validated by the token check is not bound to the value passed to
`--branch`.** The reviewer added `FIXED_BRANCH="ag-fleet-launch-proof"`, pointed only
the first `--branch` use (and its symbolic-ref expectation) at it, and left the
token-bearing `REF_PREFIX` otherwise intact. Both the static lock and the full
executable fixture exited 0 — `1 pass, 0 fail`, `launch-lane dispatch proof: PASS` —
with the fixture back to the original global collision.

Three rounds, three spellings of one defect:

| round | the lock | the mutation that defeated it |
|---|---|---|
| 1 | privatised the repository | the clone imported the existing fixed-name branch |
| 2 | static scan of `--branch` literals | assign the fixed name to `REF_PREFIX` |
| 3 | runtime token check on `REF_PREFIX` | assign the fixed name to a *different* variable |

Each round validated something adjacent to the property instead of the property.

## The lock the recut must satisfy

Assert on **the names actually created during the run** — observed at creation time, or
compared after the fact against the run's token — rather than on any variable, argument
literal or source text upstream of them. Any check that inspects a value *before* it
becomes a real ref can be bypassed by introducing one more variable, which is now
demonstrated three times.
