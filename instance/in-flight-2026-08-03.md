## Standing traps a new orchestrator will otherwise rediscover

1. `land_resolve_bun` refuses when `BUN_BIN` is set — always `env -u BUN_BIN` for a
   gate under a gate.
2. Do not use the gate's clone (`land-main`) as a working repository; orchestrator
   commits come from `orch-main`. See
   `instance/incidents/2026-08-03-orchestrator-reset-during-landing.md`.
3. A lane with a pending review reports `result: clean` +
   `remaining: Tier-A review pending`, never `NO-GO` — `NO-GO` can never land (V3-0.19).
4. Running the meteorite writes `reports/meteorite-latest.md` into the repository root
   and dirties the tree, blocking the next landing (V3-2.7).
