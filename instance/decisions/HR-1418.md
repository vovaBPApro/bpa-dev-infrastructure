## Ruling

1. **Self-hosted OCR is a product requirement, not a dev convenience:** deploy
   our own OCR on this hardware and make it **teachable from the start** —
   per-supplier templates learned from user corrections (select region /
   describe in text where a field lives), because he will not pre-build
   templates for every document in the world.
2. **Test email imports run on the PRODUCTION OCR path from day one** — no
   temporary OpenAI-CLI extraction that later migrates.
3. The teachability must be designed into the product UI and the agent's
   functionality (training flow is user-facing capability, not internal
   tooling).
4. If simple — implement right away (sequenced with the product track; the
   current key priority remains infrastructure per HR-1379).
