# HR-1439 — Generalize "unmeasured = failed" as a standing verification rule

date: 2026-08-02
source: Telegram, message 1439 (voice, whisper-local transcript)
status: binding

## Human words (verbatim, do not reword)

> Може нам це правило, невиміряне равнопровал, розповсюдити і більш якось ширше використовувати?

Context: the rule was introduced for the v3 meteorite gate after review
v3-review-7b exposed a lane printing PASS for gates it never measured
(bespoke-double self-attestation). He proposes making it general.

## Ruling

1. **Unmeasured = failed, everywhere.** Any automated gate, status surface,
   health ping, or claim that cannot externally measure its subject must
   report the subject as UNMEASURED and fail closed — never print PASS/green
   for an unmeasured thing, never silently skip.
2. Explicit skips remain possible only as tracked, reasoned, grep-able
   markers naming what arms them (the pattern reviews accepted repeatedly on
   2026-08-02) — and a skip is visibly a skip, never counted as a pass.
3. This sharpens Hard Floor 7 ("green is fail-closed") and the plan's
   "unknown is never green": the generic home is
   `instructions/verification-and-locks.md`; v3 inherits via its foundation
   copy on the next sync.

## Routing

- Instruction lane on main: fold the rule into verification-and-locks.md
  (floor-line update + regeneration), tests via the instructions checker.
