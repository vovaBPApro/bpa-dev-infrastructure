## The correction that reshaped this sprint before it started

Row V3-1.5 reads "port `meteorite/run.sh`". Reading the donor before dispatching
showed the row is **wrong as written**, and porting it faithfully would have landed a
mechanism that cannot ever pass:

```
git show v2-deprecated:meteorite/run.sh
  : "${PRODUCT_GIT_URL:?}" "${PRODUCT_GIT_REF:?}" "${PRODUCT_REBUILD_COMMAND:?}" ...
  git clone --depth 1 --branch "$PRODUCT_GIT_REF" "$PRODUCT_GIT_URL" "$repo"
```

The donor is a **product** meteorite: it clones a separate product repository and
rebuilds *that*. No product repository exists (`instance/params.yaml: phase =
sole-mission`), so the port would land a script whose only reachable outcome is a
missing-contract failure. That is precisely the defect class row V3-1.2 was rejected
for in sprint 02 — a blind port naming trees that do not exist on this line.

The mechanism actually missing is the **infrastructure** meteorite: Hard Floor 5's own
proof. On the abandoned line it was never a script at all. It was a hand-run
procedure, executed once, on 2026-07-31, recorded in
`v2-deprecated:reports/meteorite-test.md` — and its verdict was **FAIL**:

> A clean machine can clone the repository, install Bun, run the source test suites,
> and build a working Whisper stack. It cannot reproduce the deployed control plane:
> the bootstrap reports success while skipping the runtime dependencies and activation
> boundary…

So the single acceptance criterion for this entire repository has been checked exactly
once in its life, failed, and had no executor. That is the same shape as the watchdog
that had not run since 2026-08-01 and the cron that was tracked and never invoked. It
is the shape this line exists to remove.

The row is therefore re-scoped: **write** the infra meteorite runner, do not port the
product one. The product meteorite belongs to the product era and is recorded as such.

## The goal, one sentence

Make the clean-rebuild claim executable and fail-closed, and give the installer the
three stages that claim depends on — so that "wipe the server and start over" stops
being a hope and becomes a command with an exit code.
