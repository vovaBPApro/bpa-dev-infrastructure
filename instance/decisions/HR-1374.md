## Ruling

1. **Two bases feed attempt #2.** The OLD orchestrator implemented the base
   mechanisms well and the new installation did not port them properly; the NEW
   installation added good things on top (e.g., the ten personas). The
   consilium synthesis and the attempt-#2 plan must draw from BOTH, not treat
   the new tree as the only source.
2. **Team topology is a three-level hierarchy**, not a flat fleet:
   - level 1: the orchestrator (talks to the Human);
   - level 2: 10–12 agent lanes running constantly in parallel — maintained
     hard, watched strictly (extends HR-281's floor to 10–12);
   - level 3: lanes may spawn one further level of sub-agents when genuinely
     needed — delegation into sub-teams. Which roles get spawn rights is part
     of the spec, not a default for everyone.
3. Each lane may build, run its own tests, work independently.
4. The orchestrator's job includes helping lanes describe/structure this
   delegation («Ти їм просто допоможи це описати»).
5. He states this is largely already implemented («Це у нас дуже сильно вже
   реалізовано») — source-inventory the existing mechanism (old orchestrator +
   this repo's lane launcher) before writing anything new.
