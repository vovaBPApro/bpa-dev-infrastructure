## Findings

1. **Blocking — the plain-Docker stand cannot run from the image it builds.** The deny-by-default `.dockerignore` correctly excludes arbitrary worktree content, but its allowlist also excludes `daemon/server.ts` and `tests/meteorite.test.ts`. The Dockerfile sets `CMD ["bun", "daemon/server.ts"]`, and `docker/meteorite-stand.sh` starts the runner with `bun test tests/meteorite.test.ts`; both paths are absent from the exact-SHA image. This is a deterministic launcher/image contract failure.
2. **Blocking — the meteorite runner interface is not documented.** There is no tracked README/docs/scripts reference to `docker/meteorite-stand.sh` in this chain. The script is therefore not a reproducible operator interface even though it has no Compose dependency.
3. The earlier exact-SHA build and build-context leakage findings are closed: the exact-SHA build exits 0, planted untracked `review-probe.env` and `credentials/review-probe.key` do not appear in the runtime filesystem or `docker history`, and `.git` is absent.
4. The r3 fresh named-volume path passes: `docker/runtime-volume.test.sh` creates a fresh `volume-nocopy` volume, initializes it, writes through it after the privilege drop, and asserts the command UID is non-root. The entrypoint performs one non-recursive `chown` of the runtime root and then re-execs through `setpriv`; the shipped launcher also supplies read-only rootfs, `no-new-privileges`, dropped capabilities, and only `CHOWN`/`SETUID`/`SETGID`. A symlink substitution aimed at `/usr/local` failed closed on the launcher's read-only rootfs. No recursive ownership expansion was found.
5. Manifest wording is honest but bounded: `source.trackedConfig` identifies three tracked configuration inputs and verifies their hashes; it does not claim to inventory every image file. The embedded commit equals the reviewed exact SHA.
6. The chain diff contains no Docker Compose invocation or dependency. Canonical signature scanning, using `gate/land-lib.sh` from the integrated `origin/v3` boundary, found no hit.
