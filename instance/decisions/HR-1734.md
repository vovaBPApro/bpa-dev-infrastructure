# HR-1734 — Spark is the cheap tier for simple lanes

Verbatim (Vova, Telegram 1734, 2026-08-03):

> Можеш щє агентів піднімати на моделі гпт спарк для простих задач. Думаю вона дуже
> економічна

Restates Telegram 1562 (2026-08-02), which went unactioned:

> GPT-5.3-Codex-Spark - взагалі не юзається, якісь простенькі речі можна перекидати
> на нього

## State of the mechanism when this was captured

Spark cannot currently be selected for a lane. Measured at `2476ff9`:

- `daemon/model-registry.ts` contains exactly four entries — `claude-sonnet-5`,
  `claude-opus-5`, `claude-fable-5`, and `gpt-5.6-sol`. There is no Spark entry, so
  neither the Telegram `/model` command nor lane dispatch can name it.
- Spark appears in the codebase only as quota telemetry:
  `daemon/vendor-login.ts:101-102` tracks `sparkPrimaryUsedPercent` and
  `sparkSecondaryUsedPercent`. The installation therefore *measures* Spark headroom it
  has no way to *spend*.
- Subagents raised inside a Claude Code orchestrator session are limited to Claude
  models by that harness; Spark can only be reached through the codex CLI dispatch
  path, which is the lane mechanism, not the in-session subagent mechanism.

So this directive is not satisfiable by "just use Spark" today. Honouring it means
adding Spark to the registry and giving lane dispatch a tier selector.

## Rule this establishes

Cheap, mechanical lane work — inventory sweeps, mechanical refactors, evidence
collection, format normalisation, anything with a decidable acceptance criterion and
no design judgement — routes to Spark by default once routable. Reserve the expensive
tiers for design, security and Tier A review. This sharpens the existing
provider-economy default in `instructions/vendor-routing.md` (HR-210) rather than
replacing it: role fit still decides the seat (HR-1565), and cost decides the tier
within the seats that fit.

The twice-stated frustration behind this directive is that paid capacity sits unused
while scarce quota burns — the same complaint as HR-281 about idle lanes on a
12-core box.
